# BladeLogic (BMC BladeLogic / TrueSight Server Automation)

> BladeLogic is a data center automation platform for provisioning, configuring, patching, and enforcing compliance across large fleets of physical, virtual, and cloud servers. Founded in 2001 and acquired by BMC Software in 2008, it shipped as BMC BladeLogic Server Automation and later TrueSight Server Automation. It exposes a Java-based command line interface (BLCLI) and an on-premises RESTful web services API (Swagger-specified) served from the customer's own Application Server. This profile was added to the API Evangelist network from VC portfolio data (Battery Ventures, Bessemer Venture Partners) and enriched with publicly documented developer, security, and compliance surfaces.
